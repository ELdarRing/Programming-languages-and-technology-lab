1. Цель работы

Изучить JSON и хранение данных в браузере. Создать приложение учёта доходов и расходов с восстановлением записей после перезагрузки.

2. Средства разработки

HTML, CSS, JavaScript без фреймворков. Файлы проекта: index.html, style.css, app.js. Для запуска используется локальный HTTP-сервер Python. Хранилище — localStorage, ключ lab8_budget_v1.

3. Интерфейс и функции

Форма содержит тип операции, сумму, категорию, дату и описание. Таблица показывает операции выбранного месяца, кнопки изменения и удаления. Месячная сводка содержит доходы, расходы и их разность — баланс. Отдельно выводятся суммы расходов по категориям. Данные изначально отсутствуют; интерфейс показывает понятное пустое состояние.

4. Структура данных

Данные представлены массивом объектов. Пример одной записи:

[
  {
    "id": "example-1",
    "type": "expense",
    "amount": 250000,
    "category": "Продукты",
    "date": "2026-10-21",
    "note": "Учебный пример"
  }
]

id — уникальный идентификатор; type — income или expense; amount — положительная сумма в тиынах (250000 = 2500 ₸); category — категория выбранного типа; date — дата; note — описание. Целое число тиынов позволяет точно складывать денежные значения в пределах используемого диапазона.

5. Алгоритм работы

  1. При запуске читается строка из localStorage. Если ключ отсутствует, используется пустой массив.
  2. JSON.parse восстанавливает массив; проверяется структура каждой записи и уникальность идентификаторов.
  3. При добавлении или редактировании проверяются поля формы.
  4. Новый массив преобразуется в строку через JSON.stringify и сохраняется.
  5. Только после успешного сохранения обновляются состояние и интерфейс.
  6. При удалении запрашивается подтверждение; сводка пересчитывается.
const data = JSON.parse(raw);
localStorage.setItem(STORAGE_KEY, JSON.stringify(next));

6. Обработка ошибок

Приложение отклоняет пустое описание и пробелы, суммы меньше 0,01 ₸ и больше 1 млрд ₸, более двух десятичных знаков, некорректную дату и неизвестную категорию. Описание ограничено 120 символами. Чтение, разбор JSON и запись обёрнуты в try/catch. При повреждённых данных показано предупреждение, строка не перезаписывается без подтверждения. Если запись в хранилище не удалась, изменение не применяется. Пользовательский текст вставляется через textContent, без интерпретации HTML. Пароли, токены и персональные секреты не запрашиваются.

8. Демонстрация преподавателю

  1. Запустить сервер командой python3 -m http.server 8000 из папки проекта и открыть http://localhost:8000.
  2. Добавить учебный доход и расход с датами одного месяца; показать итог.
  3. Изменить сумму, затем удалить операцию.
  4. Открыть Cmd+Option+I → Application → Storage → Local Storage → адрес приложения; показать ключ lab8_budget_v1 и JSON.
  5. Обновить страницу и показать восстановление.
  6. На учебных данных удалить ключ в Storage и обновить страницу.
  7. Установить значение {broken и обновить страницу; показать обработку ошибки.
  8. Зафиксировать результаты в таблице и приложить скриншоты.

sessionStorage в данном проекте не используется, поэтому отдельная проверка сохранения в пределах вкладки к выбранной реализации не применяется.

9. Вывод

Реализовано приложение личного бюджета с созданием, просмотром, редактированием и удалением записей. Для сохранения используется JSON.stringify, для восстановления — JSON.parse. Предусмотрены валидация ввода, пустое состояние и обработка ошибок хранилища. Проверки логики завершены; браузерные проверки завершаются по приведённой инструкции.
